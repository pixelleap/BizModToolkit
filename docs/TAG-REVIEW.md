## 2. 打标规则

1. 先按关键词命中（feat 标题 + 说明 + 所属变体标题一起匹配）
2. 一个标签都没命中 → 落到模块建议标签
3. 每个 feat 最多 3 个标签，按规则表顺序截断
4. 模块（卡片）级标签同样换成新词表
